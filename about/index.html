Okay, but what is SIMAS?

Well, I'm glad you asked!

SIMAS, in a nutshell.

SIMAS, which stands for SIMple ASsembly, is a programming language designed around having high-level features (such as dynamic typing, automatic variable creation, lists, implicit type conversion, et cetera) while retaining a low-level syntax, reminiscient of Assembly.
As such, SIMAS is an assembly-like language. It is not assembly, but it resembles assembly.

Okay, but what is it like?

As mentioned earlier, SIMAS is assembly-like. This means that the general structure of the language resembles assembly.
A good example of this would be: 

add num var1 420;

where add is the instruction, and num, var1, and 420 are the operands.
Additionally, this further resembles assembly, as var1 is directly overwritten with the result of the addition operation just like in real assembly, where, for example: 

add ax, bx

would overwrite AX with the result.

However, one immediate area where you can see a difference is with the num operand, as SIMAS is an explicitly (though dynamically) typed language, which is radically different from assembly (where it's all just numbers).
SIMAS supports three fundamental data types: NUM (a double-precision floating point number), STR (a string of characters), and BOOL (a boolean, true or false).
These three data types hold up the core instructions of the SIMAS language, and as a bonus, all three can be freely converted between.
